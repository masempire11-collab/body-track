# BODY TRACK DUO v0.3

Обновление BODY TRACK v0.2.1. Один iPhone, совместные и индивидуальные тренировки.

## Установка
Замените в корне GitHub Pages `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` файлами из архива. Дождитесь публикации.

## Важно
Перед обновлением экспортируйте JSON в разделе «Данные». База сохраняется под старым ключом `bodytrack-v02`. Существующие записи без `participants` считаются совместными для обратной совместимости; это не подтверждает фактическое присутствие обоих. Новые тренировки получают явный список участников. Черновик сохраняется отдельно в `bodytrack-v03-draft`. Данные находятся только на устройстве, синхронизации нет.

## Новое
- выбор Артём / Дамир / оба;
- отдельная история и прошлые веса для каждого;
- сворачиваемые упражнения;
- автосохранение черновика и восстановление;
- таймер отдыха;
- мобильные правки форм.

Исторические записи из заметок не подтверждены и не должны трактоваться как выполненные подходы.
