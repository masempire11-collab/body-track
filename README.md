# BODY TRACK PRO 0.3.1

Премиальный интерфейс, одновременный ввод подходов Артёма и Дамира, индивидуальные тренировки, независимая история, дроп-сеты по запросу, автосохранение черновика.

Замените index.html, sw.js, manifest.webmanifest и icon.svg в GitHub Pages. Перед обновлением экспортируйте JSON из вкладки «Данные». Данные сохраняются в localStorage браузера.
