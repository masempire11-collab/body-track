# BODY TRACK DUO v0.2

Локальное PWA-приложение для ведения совместных тренировок Артёма и Дамира на одном iPhone.

## Развёртывание

Загрузите `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg` в корень публичного GitHub-репозитория. В Settings → Pages выберите Deploy from a branch, main, /(root). Откройте HTTPS-адрес GitHub Pages в Safari и добавьте на экран «Домой».

## Данные

Сохранение: `localStorage` браузера, ключ `bodytrack-v02`. Резервное копирование: раздел «Данные» → «Скачать JSON». При первом открытии существующие данные v0.1 не стираются. Перенос: «Данные» → «Перенести локальные записи v0.1», если обе версии открывались на одном origin, либо экспорт JSON из v0.1 и импорт в v0.2.

Исторические записи из переписки использованы для названий упражнений, схем повторений и групп суперсетов. Неполные веса не импортируются автоматически как достоверные результаты. Существующие записи v0.1 можно импортировать отдельно.

Приложение не имеет сервера и синхронизации. При очистке данных браузера записи могут исчезнуть. Не публикуйте личные записи в репозитории.
