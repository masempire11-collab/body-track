BODY TRACK PRO v0.3.2

Добавлена замена упражнения только в текущей тренировке через «Заменить сегодня».
Шаблон программы не изменяется. В истории фиксируется исходное название и замена.
Если уже были выполненные подходы, они сохраняются отдельной записью в той же тренировке.
Веса для заменяющего упражнения не копируются из исходного.

Перед обновлением экспортируйте JSON во вкладке «Данные». Загрузите файлы проекта в корень GitHub Pages.
