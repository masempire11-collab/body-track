# BODY TRACK PRO 0.3.4 — Executive Performance

Обновление существующей PWA без изменения ключа localStorage.

## Изменения
- Премиальная графитово-золотая тема для всех экранов.
- Вес и повторы подставляются только из отмеченных выполненными подходов завершённых тренировок.
- При создании новой тренировки галочки пустые.
- Плановые повторения больше не показываются в карточках подходов.
- При замене упражнения используются последние выполненные результаты именно нового упражнения, если они есть.
- Поддерживаются совместные и одиночные тренировки, дроп-сеты, суперсеты, история, замеры и JSON экспорт.

Перед обновлением сделайте экспорт JSON через вкладку «Данные». Загрузите index.html, sw.js, manifest.webmanifest, icon.svg в корень GitHub Pages.

Проверка: синтаксис JavaScript и целостность ZIP; тестирование в Safari на физическом iPhone требуется.
